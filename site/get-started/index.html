Get started

From zero to your dashboard in a minute.

GitMetrics runs on your own computer and opens in your browser. Run one command, sign in with GitHub, and every repository you can reach is ready to explore.

  1. Check that you have Node.js

    GitMetrics needs Node.js 20.19 or newer, on Windows, macOS or Linux. To see your version:

    $ node --version

  2. Run GitMetrics

    Nothing to install: npx downloads the latest version and runs it, every time.

    $ npx @gitmetrics/app

    Install it once, then open it anytime with the gitmetrics command.

    $ npm install -g @gitmetrics/app
    $ gitmetrics

    Your browser opens on http://localhost:4280, served by your own computer only.

  3. Sign in with GitHub

    GitMetrics uses your own GitHub access, so it sees exactly what you can see.

    • Continue with GitHub CLI

      If you use the GitHub CLI, one click reuses its session.

    • Use a personal access token

      Create a token with repo, read:user and read:org, then paste it.

    Your token is kept in ~/.gitmetrics, readable by your user alone. Signing out deletes it.

  4. Explore your repositories

    Open any repository to see its numbers, or press Ctrl K to jump straight to one, or to a pull request by pasting its link.

Keeping it up to date

Started with npx, GitMetrics updates itself. Installed globally, it tells you when a new version is out, and this updates it:

$ npm install -g @gitmetrics/app@latest
