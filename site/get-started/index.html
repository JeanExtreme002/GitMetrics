Get started

From zero to your dashboard in a minute.

GitMetrics runs on your own computer and opens in your browser. Pick how you want to run it, sign in with GitHub, and every repository you can reach is ready to explore.

1

Check the requirements

You need Node.js 20.19 or newer, on Windows, Linux or macOS. To check your version:

$ node --version
2

Run GitMetrics

Try it right away with npx, which downloads and runs the latest version:

$ npx @gitmetrics/app

Or install it once and open it anytime with the gitmetrics command:

$ npm install -g @gitmetrics/app
$ gitmetrics

Your browser opens on http://localhost:4280. The server only listens on your own computer.

3

Sign in with GitHub

GitMetrics uses your own GitHub access, so it sees exactly what you can see. Two ways to sign in:

With the GitHub CLI
If you use the GitHub CLI, one click reuses your session.
With a personal access token
Create a token with the repo, read:user and read:org scopes, then paste it on the sign-in screen.

Your token is stored only in ~/.gitmetrics, readable by your user alone. Signing out deletes it.

4

Explore your repositories

Open any repository to see its numbers, or press Ctrl + K to jump straight to one.

Want to know more? Every option and the source code are on GitHub.

View on GitHub

Update

npx always runs the latest version. For a global install:

$ npm install -g @gitmetrics/app@latest
