What people ask before trying GitMetrics.

Ask something else →
Is GitMetrics free?

Yes. It's free and open source under the GNU AGPL-3.0, with no paid plan and no account to create.

Is it made by GitHub?

No. GitMetrics is an independent open source project. It uses GitHub's public API with your own sign-in, the same way the GitHub CLI does.

Where does my GitHub token go?

Only to api.github.com. It's saved in ~/.gitmetrics/config.json, a file only your user can read, and signing out deletes it.

Which permissions does it ask for?

repo, read:user and read:org, so it can read your private repositories and organizations. GitHub has no narrower scope for private repositories, but GitMetrics only ever reads.

Does it work with private repositories and organizations?

Yes. It shows everything your account can see, including traffic where you have push access.

How is traffic kept beyond GitHub's 14 days?

Each day GitMetrics runs, it saves the views and clones of your repositories on your computer. Open it at least every two weeks and the history never has a gap.

How do I update it?

You don't have to: started with npx, it restarts into the newest version on its own. Installed with npm install -g, it shows the command that updates it.

Install once, run it anytime.
