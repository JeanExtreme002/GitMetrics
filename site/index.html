GitMetrics
Features npm GitHub

Free, open source and local

Every number behind your GitHub repositories.

Stars, traffic, commits, pull requests and CI health in one fast dashboard that runs on your own machine. No account, no backend, nothing to configure.

$ npx @gitmetrics/app

Needs Node.js 20.19 or newer. Runs on Windows, Linux and macOS.

View on GitHub See what's inside

What GitHub leaves out, in one place.

GitHub shows bits of your projects in scattered places and forgets older traffic. GitMetrics fills those gaps.

Traffic that never expires

GitHub keeps two weeks of views and clones. GitMetrics saves every window on your machine, so the history keeps growing for as long as you use it.

The full story of each repository

Star history, pull requests, issues, contributors, hotspots, Actions, releases and deployments, each on its own focused page.

Exact numbers, even on busy repos

Monthly pull requests and issues, daily workflow runs and deployment totals come from GitHub's own counts, not from a small sample.

Everything you own, side by side

A home page across all your repositories and organizations, rankings by stars, activity or traffic, and Ctrl + K to jump anywhere.

Private by design

It runs on 127.0.0.1 and talks only to api.github.com. Your token and data never leave your computer.

One command away

No signup and no setup. Run it with npx, sign in with the GitHub CLI or a token, and start exploring.

A page for every question.

How fast is it growing? Who is building it? Is the CI healthy? Each answer is one click away.

Try it in seconds.

$ npx @gitmetrics/app

Built in the open. Follow the project, share ideas or contribute on GitHub.
